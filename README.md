# MapCraft

日本の地名・駅名・住所を検索して範囲を選び、Minecraftのワールドを生成するWindows向けツールです。Windows統合版では、実地図ミニマップ、到着通知、地域に応じた宝箱、ランダムなベッド、人口に応じた村人を設定できます。

MapCraft独自のソースはMITライセンスです。**エンジン・ライブラリ・地図データには別の条件があり、配布物全体がMITになるわけではありません。** 公開・再配布する場合は、末尾の「ライセンスと配布条件」を確認してください。

**0.21.1-preview / 開発版**。広域生成とゲーム内表示のすべてを検証済みの安定版ではありません。

## 遊ぶ方

作成者から渡された `.mcworld` を開き、Minecraft for Windowsへ取り込んでください。宝箱と中身・ベッド・村人・動物・ボスは通常のワールドデータとして保存され、追加MODやパックなしで利用できます。PythonやMapCraftの常駐も不要です。

実地図ミニマップと到着通知は任意のワールド専用パックを使用します。

`.mcaddon` だけを受け取った場合は、そのアドオンに対応するワールドも必要です。取り込み後、ワールド編集で対応するビヘイビアーとリソースの両方を有効にします。Java版のMODファイルとは別の仕組みです。

地理座標や地図を含むため、**どのワールドにも使える汎用の単体アドオンではありません**。作成したワールドごとに対応アドオンを出力します。配布用には、ワールドごとのプレイヤーZIPを作成できます。

## ワールドを作る方

実行用ZIPの公開状況は [Releases](https://github.com/taaakumiii/MapCraft/releases) を確認してください。実行用ZIPが未提供の場合は、後述のソースからの実行手順を使用します。GitHubの「Download ZIP」はソースコードであり、EXE・エンジン・ランタイム・全国OSMデータ・生成済みワールドは含みません。

1. Creator ZIPをフォルダーごと展開し、`MapCraft.exe` を開きます。実行ファイルだけを取り出さないでください。
2. 地名・駅名・住所を検索し、候補を選びます。「範囲を描く」でドラッグするか、検索結果の範囲を指定します。
3. 出力形式、縮尺、必要な詳細設定を選び、生成します。
4. 完成した `.mcworld` を開いて遊ぶか、他の方へ渡します。更新アドオンは「ゲーム内の実地図を取り込む」の「対象…」で作成できます。

通常モードは実際の地形に対応します。全国モードは固定の全国座標に区画を追加する方式で、**地面の高さは一定**です。現実の山の高さを全国に再現する機能ではありません。

縮尺は `1m＝1ブロック`、`2m＝1ブロック`、`約3m＝1ブロック` から選べます。通常モードの選択範囲は最大300km²です。それより広い範囲は、次の全国・地域メニューを使用してください。

### 全国・都道府県・地方から出力

「全国・都道府県・地方から出力…」で、日本全国・47都道府県・8地方・地図の選択範囲を指定できます。地方は北海道／東北／関東／中部／近畿／中国／四国／九州・沖縄です（三重県は近畿）。「選択範囲を生成して .mcworld に出力 / 再開」は、区画を保存しながら対象範囲を生成し、完了後に出力します。途中停止や失敗後は同じ保存先で再開してください。

都道府県・地方・全国の範囲は国土交通省の行政区域N03 2026を必要な県だけ取得・再利用し、陸地・島と約500mの沿岸を生成します。島の間と対象外の未生成部分は一定水深の簡易海です。拡張する場合は、元の作成用プロジェクトを「参照…」で選び、既存の県すべてを含む地方または全国を選択して「選択範囲へ拡張」を押します。出力済み・取り込み済みのプレイワールドには追記しません。

1. 範囲・保存先・縮尺・オプションを選びます。
2. 日本のOSMデータを取得し、索引作成を完了させます。取得データと索引は再利用できます。
3. 「選択範囲を生成して .mcworld に出力 / 再開」を実行します。
4. 地形・追加処理・出力がすべて完了したら、完成した `.mcworld` を取り込みます。

全国を新規作成した場合の初期スポーンは東京駅付近です。都道府県・地方では選択範囲内へ調整します。**対象外の未生成部分は、現実には陸地であっても簡易海になります。** その場所で遊ぶには追加生成が必要です。

東京都 → 関東 → 全国のように拡張できます。遊ぶための完成ファイルを先に別保存し、元の作成用プロジェクトを拡張してください。既存プロジェクトからの出力対象は**生成済み範囲全体**で、選択地域だけを切り抜く機能ではありません。拡張を続ける場合は、元のプロジェクト・設定・必要なデータも保持してください。

### 主な追加機能と初期設定

以下は**新規GUI設定**の初期値です。既存プロジェクトや再開処理では保存済み設定を使用します。これらの追加機能はWindows統合版向けです。

- 宝箱は各フロアを独立に抽選し、当選した階へ最大1箱。既定25%で、オン・オフと0〜100%の確率を変更できます。ベッドは建物ごとの独立した抽選で、既定25%です。
- 村人は標準オンで、実人口250人につき1人です。2026年1月の市区町村人口を生成範囲の面積で按分し、住宅内や安全な屋外候補へ通常の村人として事前配置します。実際の建物ごとの居住人数を再現するものではなく、安全な候補が少ない場合は人数が減ります。
- 動物は標準オン・多さ200%です。海辺のカメ、山のヤギ・ウサギ、森林のキツネ・オオカミ、農地の牛・豚・鶏、水域の魚などを、生息地に合わせて生成時に保存します。追加MODやパックは不要で、多さを設定できます。
- ボスは標準オフ。詳細設定でオンにすると、神社・寺院・墓地に、面積に応じた通常のボスとレア品入り宝箱を事前配置します。小規模はブルート、順にエルダー・ウォーデン・ウィザー、最大規模はエンド入口です。倒した後の自動復活はありません。
- ボスのビーコンは標準オンです。ボス配置を有効にした場合に、安全な設置場所があれば目印を配置します。敵は通常のMinecraftの挙動に従い、ウィザーの地形破壊や難易度による消失などが起こります。
- 活火山周辺は地下と宝箱で鉱物が増え、火山直下に小さなマグマだまりを作ります。気象庁の実際の火山位置を使ったゲーム用モデルです。
- Windows統合版の宝箱・中身・ベッド・村人・動物・ボスは生成時に通常のデータとして保存します。ミニマップは標準オフで、通常の高さなら追加パックなしのマップを出力します。実地図ミニマップ・到着通知だけがオプションのパックです。
- 店舗周辺は食料、農地は作物、工業地帯は道具・素材などが出やすくなります。サバイバルで入手可能なアイテムのカタログを用い、貴重品の確率と個数を抑えて抽選します。すべてのアイテムが1つの地域やワールドで必ず出るわけではありません。
- すでに配置した宝箱・ベッドは補充や再配置をしません。家具を置ける屋内がない建物は省略します。
- 地下充填は既定オン。公的地質を参照する地下素材はWindows統合版向けです。地下の深さや鉱石の確率はゲーム用モデルであり、実際の鉱床を示しません。
- 地盤計算はGPU/CPUを自動比較して速い方を使用します。対応GPU・ドライバーがないPCやGPUエラー時はCPUで続行します。GPUは必須ではありません。詳細設定で自動判定をオフにするとCPUのみを使用します。
- 海底地形は標準オン・最大水深60ブロックです。ETOPOの粗い海底標高データを補間するため、小さな浅瀬や港湾の精密な再現はできません。
- 地下鉄はOSMに登録された路線から可能な範囲で再現します。未登録施設や地下設備全体の実測再現ではありません。
- 到着通知は、取得できた自治体境界に基づいて「プレイヤー名が、○○町に到着」と表示します。
- 実地図ミニマップは右上に表示し、海・川・湖は青色で描きます。プレイ中の外部地図アプリは不要です。
- 失敗・中止した通常生成は「履歴・再試行…」で再開します。エンジンの途中生成は工程の再実行になります。全国モードは保存済み区画を再利用します。

詳しい手順は [利用ガイド](docs/USER-GUIDE.md) を参照してください。

### 状況確認・一時停止・再開

メイン画面右上の「生成状況・一時停止・再開…」では、保存済みの地形区画・実地図区画、現在の工程、出力予定先を確認できます。「保存して一時停止」を押し、「PCをシャットダウンできます」と表示されるまで待ってから終了してください。PC再起動後はMapCraftを開き、同じ画面の「再開」で続行します。再開した処理はバックグラウンドで実行されるため、MapCraftの画面を閉じても続きます。全国・地域メニューから開始した処理の設定も保持します。通常の小範囲生成は従来の「履歴・再試行」を使用してください。

「状況を問い合わせる」で最新情報を確認できます。**地形が100%でも、地図画像・追加配置・圧縮出力が残っている場合があります。** 全体の工程と出力完了を確認してください。未完了の工程や区画は再実行される場合があります。

## 動作環境と通信

- Windows x64、Minecraft for Windows。追加配置はMinecraft 1.26.60以降を対象にしています。アドオンは `@minecraft/server 2.6.0` / `@minecraft/server-ui 2.1.0` 対応環境を前提とします。Java版は通常のワールド生成を利用できますが、広域生成・地質・家具・モブ追加・Bedrockアドオン機能は対象外です。
- 生成時にインターネット接続が必要です。検索語はPhotonへ、選択範囲はOpenStreetMapのタイル・Overpass、Arnisのデータ提供元、公的地質サービスなどへ送信されます。
- 地図データはOpenStreetMap等の公開地理データを利用します。Google Maps画像の複製・保存やGoogle Maps API連携を提供するものではありません。
- プレイ用ZIPに必要な地図画像・境界データを同梱するため、プレイ中の外部補助アプリは不要です。
- 等倍・広域生成には非常に大きな時間と容量が必要です。全国を短時間で作成できる保証はなく、数TB規模になる可能性があります。完成ファイルの出力用にも空き容量を確保してください。
- 再出力した `.mcworld` に、取り込み後のプレイワールドの建築や取得済みアイテムを統合する機能はありません。

マルチでは、参加者がCreatorやJava MODを事前導入する必要はありません。ミニマップ付きワールドではMinecraftが接続先のパックを取得・適用します。取得の確認や必須設定は接続方法によります。実機でのマルチ参加・就寝の最終確認は未実施です。

## ソースから実行・ビルド

Windows x64上でPython 3.12を用意し、リポジトリ直下で実行します。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe scripts/bootstrap_runtime.py
.\.venv\Scripts\python.exe app.py
```

`bootstrap_runtime.py` は指定版のArnis・Pythonランタイムなどを取得し、ハッシュを確認して配置します。初回はダウンロードの時間と容量が必要です。

テストと配布ZIPの作成：

```powershell
.\engine\national-runtime\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm MapCraft.spec
.\.venv\Scripts\python.exe scripts/package_release.py
```

Windows x64上でビルドします。GUI部分はPython 3.12以降を想定し、全国・地質処理は同梱のPython 3.12ランタイムで動作します。ソースのGit管理には、エンジン、ランタイム、OSM、生成ワールド、キャッシュを含めません。GitHub Actionsの `Build Windows distribution` は手動実行で作成者用ZIPをビルドできます。

配布物は `release/` に出力します。ビルド成功だけで、再配布条件の確認やゲーム内検証が完了するわけではありません。
