# 利用ガイド

## Creator ZIP

ZIP全体を、書き込み可能なフォルダーへ展開します。`MapCraft.exe`で起動します。`engine`、`native_minimap`、PythonソースやJavaScriptは削除しないでください。通常のプレイヤーはCreator ZIPをインストールする必要はありません。

場所の検索 → 候補を選択 → 範囲指定 → 出力形式・縮尺 → 生成、の順に進めます。詳細設定で地形・地下・宝箱・ベッドを設定できます。入力欄は0〜100%で、小数にも対応します。

宝箱の「各フロアの配置確率」は、検出した各階に独立して適用します。既定25%なら、1階・2階・3階それぞれで25%の抽選を行い、当選した階に最大1箱を配置します。0%は配置なし、100%は配置可能な各階に1箱です。実際に生成された床・天井・壁と空きスペースで判定し、屋上や床のない吹き抜けには配置しません。階数情報だけから床や階段を追加する機能ではありません。

地盤計算の「対応GPUで地盤計算を高速化」は既定オンです。最初に速度と出力内容を比較し、GPUが速い場合だけ使用します。現在のGPU対応はWindowsのNVIDIA CUDAドライバー経由です。GPU未搭載・未対応・古いドライバー・メモリー不足などの場合や途中のGPUエラー時は、CPUで続行します。GPUがなくても同じCreator ZIPを使えます。CUDA Toolkitや追加のPython GPUライブラリを手動導入する必要はありません。CPUのみで動かしたい場合はチェックを外します。

生成が完了すると、完成ワールドを開く操作が使えます。失敗したときは「履歴・再試行…」で対象フォルダーを選択します。設定を変えて作り直す場合は新規生成にしてください。

## 全国モード

1. 「日本全国を1つのワールドへ…」を開きます。
2. https://download.geofabrik.de/asia/japan.html から日本の`.osm.pbf`を保存し、選択します。
3. 「全国データの索引を作成」で読み込みます。索引の作成には追加容量と時間が必要です。途中終了した索引は再読み込みになります。
4. 保存先、縮尺、範囲を選び、「新規プロジェクトを作成」を押します。全国と地域限定は同じ全国座標を使用します。
5. 「1区画を生成」で試します。全国の初期位置は東京駅丸の内側付近です。地域限定では指定範囲内の開始位置になります。
6. 「残りを続けて生成 / 再開」で続行します。停止する場合は「現在の区画後に一時停止」を使います。
7. 生成済み範囲を`.mcworld`へ出力します。これはスナップショットであり、取り込み済みワールドに後から追記する機能ではありません。

全国は平地の道路・建物版です。既存データの精度や欠落により、建物・地下鉄・地名などが省略されることがあります。全国全区画の完成ワールドでの動作や、数TBのファイルのMinecraftへの取り込みは検証していません。まず小範囲で確認してください。

## Player ZIP / アドオン

通常は`.mcworld`を開くだけで、対応する地図とスクリプトが有効になります。更新用`.mcaddon`を使うときは、同じワールドID用であることを確認し、ワールド編集でビヘイビアーとリソースの両方を有効にします。

ミニマップはゲーム画面右上に表示します。コンパスを使うか`/mapcraft:menu`で倍率を変更します。到着通知とミニマップはアドオンの機能です。0.14以降の宝箱・中身・ベッドは生成時にワールドへ保存するため、アドオンなしでも存在します。

パックを使わず配布する場合は、通常生成の詳細設定で「実地図ミニマップ・到着通知を同梱する」をオフにします。通常の高さで生成してください。高さ拡張用の独自ディメンションがあるワールドは完全なパックなし版に変換できません。パックなし版のPlayer ZIPには`.mcaddon`は含まれません。

マルチのホストはワールドを開き、参加者は通常どおり接続します。ミニマップ付きの場合は接続時にMinecraft内で必要なパックを取得します。確認表示や必須取得の扱いはホスト設定・接続先によります。参加者へCreator ZIPやPythonを配布する必要はありません。

Java版にはBedrockアドオンを入れられません。CreatorのJava出力は利用できますが、ここで説明するゲーム機能はWindows統合版向けです。

## 地下とアイテム

詳細設定の「住宅内に村人を生成する」をオンにすると、住民を生成できます。標準はオフです。「実人口何人につき村人1人」は標準1,000で、小さい数ほど増えます（100〜100,000）。例えば人口密度20,000人/km²の市内を1km²生成すると約20人、200人/km²なら平均0.2人です。小数分は再試行でも同じ結果になる抽選で扱います。2026年1月1日現在の総務省の市区町村人口（日本人・外国人の総計）を自治体の面積で按分する近似で、街区ごとの実際の居住分布を再現するものではありません。

村人は住宅の床・天井・壁と空きスペースを確認して事前配置します。配置可能な場所が足りない場合は少なくなります。名前の重複等で人口表に照合できない自治体はログで通知し、推測した人数は配置しません。通常のBedrock村人として保存するため、ミニマップを同梱しないワールドやマルチでも表示用アドオンは不要です。全国モードではプロジェクト新規作成時の設定を保存し、出力時に生成済み地域へ配置します。既存ワールドへの後付け編集や、死亡した住民の自動補充は行いません。Java出力には適用しません。

公的地質の反映をオンにすると、気象庁の活火山の代表地点から10km以内は鉄・銅などの地下鉱物がやや増え、代表地点のごく近くの深部に小さなマグマだまりを作ります。元の普通の石だけを対象とし、空気・地下鉄・既存の鉱石・水を置き換えません。火山近傍の宝箱も通常・準貴重の鉱物系が増えますが、貴重品の確率は増やしません。マグマの深さ・形・範囲や鉱物の分布はゲーム用の演出で、実際の地下構造や鉱床の情報ではありません。既存の完成ワールドへの変更には新規生成が必要です。

地中充填は地面Y=64を基準にします。公的地質の反映は、生成した普通の石の一部をY=1〜56で変更します。元の岩盤・鉱石・空気・線路等は保持します。地層の深さと鉱石確率はゲーム用の調整です。

宝箱は1箱3〜6枠で、地域に応じた傾向を持ちます。収録カタログはサバイバル用1,487種類で、事前配置はBedrock 1.26.60以降を対象とします。古いゲームで未収録のアイテムは利用できません。管理用・スポーンエッグなどは除外し、色や本の文章など全データ状態を列挙する機能ではありません。

貴重品は最大1枠・1個、1箱あたり合計約0.8%の枠です。既存のチェストは変更せず、取り出した品や壊した家具を補充しません。

## 保存・問い合わせ

生成先フォルダー、生成情報、キャッシュを保持すると再試行で再利用できます。公開する場合は、端末パスやプレイヤー名を含むログをそのまま貼らず、必要な部分だけを確認してください。
