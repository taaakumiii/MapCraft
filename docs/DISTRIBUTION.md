# 配布手順

## 成果物

| 対象 | 渡すもの |
|---|---|
| ワールドを作成する人 | `MapCraft-Creator-<version>-windows-x64.zip`をフォルダーごと |
| すでに作成した地域を遊ぶ人 | 対応する`.mcworld`と、必要なら同じワールドID用の更新`.mcaddon` |
| 開発する人 | このソースリポジトリまたはソースZIP |

Creator ZIPにはエンジンと隔離ランタイムを含めます。プレイヤー用ZIPには含めません。Minecraft本体はどちらにも含めません。

プレイヤー用アドオンはワールドの地図と座標に対応します。ひとつの汎用アドオンを、座標の異なるすべてのワールドにそのまま配布することはできません。

## 作成者用ZIP

`scripts/package_release.py`が明示的なファイルリストからZIPを作り、各ファイルのSHA-256を`FILE-MANIFEST.json`に記録します。生成ワールド、地図キャッシュ、PBF、索引、個人の自動処理設定、認証情報を収集しません。

```powershell
python scripts/package_release.py --out release
```

通常のReleaseにはソースZIPも添付します。GitHubの自動ソースアーカイブを使う場合でも、ローカルのエンジンやランタイムをGitへ追加しないでください。

## プレイヤー用ZIP

生成直後の、まだプレイしていないワールドを使用します。プレイ済みワールドには、プレイヤー情報や建築などが含まれる可能性があります。次の補助スクリプトは作成者のメタデータパスを除去しますが、プレイヤーデータを消す機能ではありません。

```powershell
python scripts/player_package.py --world path\to\generated.mcworld --out release\players --name MapCraft-MyArea
```

パック付きワールドでは、対応するパックを`.mcaddon`にもまとめます。パックなし版では家具と中身を含む`.mcworld`だけを作成します。部品のUUIDを保ち、ビヘイビアーとリソースのバージョンを揃えます。導入手順と出典を必ず一緒に配布してください。

配布用のTokyo Demoは東京駅付近の最初の1区画だけを対象にした試遊用です。全国完成版ではありません。更新された完成ワールドへ試遊中の建築を統合する機能もありません。

## 公開前に確認するもの

- エンジン、ランタイム、借用素材のライセンス原文とRequired Noticeを残します。MapCraftのMITだけで配布物全体を説明しません。
- Amulet Team Licenseの用途・非競合に関する条件を確認します。販売や商用サービス化の可否を、このプロジェクトのMIT表示から判断しないでください。
- 地図データ・地質データの出典と元データへのリンクを保持します。
- 生成途中のファイル、端末固有パス、プレイヤー情報、秘密情報、全国PBFや索引をGitに含めないことを確認します。
- Creator ZIPの空フォルダーからの起動と、実ゲームへの取り込みを確認します。プレビュー段階の未確認事項はRelease説明に残します。

GitHubへ置くエンジン等のバイナリはソースツリーではなくRelease添付ファイルとして扱います。リポジトリの公開範囲とReleaseの発行状態は別です。準備中は非公開リポジトリとDraft Releaseで保管できます。
